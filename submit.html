📝 내 봇 URL 등록하기

Vercel에 배포한 봇 링크를 카드에 표시하는 방법

← 메인으로

🎯 무엇을 하나요?

본인 봇을 Vercel에 배포했으면, 그 URL을 bots.json 파일에 등록하세요.

등록되면 메인 페이지 카드에 "🔗 체험하기" 버튼이 활성화됩니다.

방법 ① — GitHub 웹 에디터 (가장 쉬움) ⭐

설치 / 클론 / 명령어 X. GitHub 웹사이트에서 직접 수정합니다.

STEP 1

GitHub 로그인 후 bots.json 파일 열기:

📂 bots.json 열기

STEP 2

우측 상단 연필 아이콘 (✏️) 클릭 → "Edit this file"

STEP 3

본인 팀 번호를 찾아 "webAppUrl": "" 부분을 본인 Vercel URL로 교체:

{
  "teamNum": "01",
  "botName": "식구",
  ...
  "webAppUrl": ""  ← 여기를 본인 URL로
}

↓ 변경 후

{
  "teamNum": "01",
  "botName": "식구",
  ...
  "webAppUrl": "https://my-sikgu-bot.vercel.app"
}
⚠️ 주의사항
  • 다른 팀 정보는 절대 건드리지 마세요
  • 큰따옴표 " 빠뜨리면 안 됨
  • URL 끝에 / 있어도 OK
STEP 4

화면 하단 "Commit changes..." 버튼 클릭

  • 커밋 메시지 예: Add webApp URL for team 01 (식구)
  • collaborator라면: "Commit directly to main" 선택 → 바로 반영
  • 아니면: 자동으로 PR(Pull Request) 만들어짐 → 교수님이 승인 후 반영
STEP 5

1~2분 후 메인 페이지 새로고침:

🏠 메인 페이지 확인

방법 ② — Git CLI (개발자용)

이미 레포를 클론했거나 git 명령어가 익숙한 경우.

git clone https://github.com/sdkparkforbi/bizmodel-bots-2026.git
cd bizmodel-bots-2026
# VS Code 등으로 bots.json 편집
git add bots.json
git commit -m "Add webApp URL for team 01"
git push

방법 ③ — 교수님께 카톡 전송 (가장 빠름)

GitHub 없이 그냥 본인 URL을 카톡으로 보내면 교수님이 등록.

안녕하세요!
TEAM 01 식구 (김수연) URL입니다.
https://my-sikgu-bot.vercel.app
💡 추천 개발 공부 측면에서는 방법 ① (GitHub 웹 에디터) 시도해보는 걸 권장합니다. 나중에 본인 봇 수정/배포에 익숙해질 수 있어요.

🆘 문제가 생기면

  • "체험하기" 버튼이 안 보임 → 브라우저 새로고침 (Ctrl+F5)
  • JSON 문법 에러 → jsonlint.com에서 검증 후 다시 커밋
  • PR 승인 대기 중 → 교수님께 카톡으로 알림
  • URL이 작동 안 함 → Vercel 대시보드에서 배포 상태 확인
